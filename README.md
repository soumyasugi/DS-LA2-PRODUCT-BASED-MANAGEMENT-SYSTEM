🛒 Product Management System Using Binary Search Tree (BST)

📌 Project Overview

The Product Management System Using Binary Search Tree (BST) is a web-based application developed using HTML, CSS, and JavaScript.

This project uses the Binary Search Tree data structure to manage product information efficiently. Users can perform different operations such as adding, searching, deleting, and displaying products based on their Product ID

The main purpose of this project is to demonstrate the practical implementation of Data Structures and Algorithms in a real-world application.

---

🎯 Objectives

- To understand and implement the Binary Search Tree data structure.
- To manage product information efficiently.
- To perform insertion, searching, and deletion operations.
- To display products in sorted order using tree traversal.
- To develop an interactive and user-friendly web application.

✨ Features

1. Add Product

Allows users to add new products with details such as Product ID, Product Name, Price, and Quantity.

2. Search Product

Allows users to search for a particular product using its Product ID.

3. Delete Product

Removes a selected product from the Binary Search Tree using its Product ID.

4. Display Products

Displays the available products stored in the system.

5. Sorted Product Display

Uses Inorder Traversal to display products in ascending order of Product ID.

🌳 Data Structure Used – Binary Search Tree

A Binary Search Tree (BST) is a non-linear data structure in which each node contains data and has at most two children.

Properties of BST

- The left subtree contains smaller values than the parent node.
- The right subtree contains greater values than the parent node.
- Each node represents a product.
- Duplicate Product IDs are not allowed.

Example of Binary Search Tree

             50
           /    \
         30      70
        /  \    /  \
       20  40  60  80

Here, each number represents a Product ID.

---

⚙️ Operations Performed

Operation| Description
Insertion| Adds a new product into the BST
Searching| Finds a product using its ID
Deletion| Removes a product from the BST
Inorder Traversal| Displays products in ascending order

Operation| Average Case| Worst Case
